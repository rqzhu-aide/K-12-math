Experimental features

Optional Ailleo services are managed by the site operator. You do not need to enter an API key for them.

If you enable speech-to-text, stopping a recording sends the audio to Ailleo’s server. If you also enable Sentiment Check, the app automatically sends the original transcript and question before you edit the transcript or press Submit. Ailleo processes this temporarily, without keeping the audio, original transcript or sentiment results as learner records.

Improving question recommendations

Ailleo’s collection for question recommendations is off. Enabling a feature gives permission only for processing.

If sharing becomes available and you separately opt in, Ailleo will keep only the final text you explicitly submit in ‘Your thinking’ for up to 90 days to improve its internal question recommendations. This can include typed text or speech-to-text output that you submit with or without edits.
