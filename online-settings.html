Connect with

Use an OpenAI-compatible API that permits requests from this website. Requests go directly from your browser to your chosen provider.

Your API key is kept only for this browser tab session. It is sent directly to the provider you choose. Provider charges and data-use policies apply.

ChatGPT sign-in needs a small helper running on the same computer as this browser. Your ChatGPT credentials stay on your device.

  1. Download the tutor helper and extract the ZIP.
  2. Start the helper on this computer and keep its terminal open.
    Start instructions

    The helper uses your system Python installation. Install Python and its packages globally as described in the included README. No runtime is bundled.

    Windows: Start Tutor Companion.cmd
    macOS / Linux: sh start-tutor-companion.sh

  3. Paste the pairing key printed by the helper, then connect and sign in.

The pairing key is kept only for this tab session. Restarting the helper creates a new key. If your browser asks for local-network access, allow it for this site.

Confidence & sentiment model

Not connected

Uses your original speech transcript to observe expressed confidence and engagement, and how clearly you explain your thinking. Clarity describes the explanation, not mathematical correctness. No voice tone is analyzed.

This service will appear when the site operator connects the desktop service to a public address. You can keep using the question bank and your own tutor.
