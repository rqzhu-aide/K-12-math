Ailleo Math Practice Service

This optional service includes Speech-to-Text LLM and Sentiment Check LLM. Ailleo provides both without an API key from you.

If you enable both features, stopping a recording sends the audio to Ailleo for transcription. The app then automatically sends the original transcript and question for Sentiment Check before you edit the text or press Submit. Ailleo uses the audio, original transcript and sentiment results only for temporary processing.

You can practice by typing and turn off this service at any time.

Improving question recommendations

Ailleo’s collection for question recommendations is off. Enabling a feature gives permission only for processing.

If sharing becomes available and you separately opt in, Ailleo will keep only the final text you explicitly submit in ‘Your thinking’ for up to 90 days to improve its internal question recommendations. This can include typed text or speech-to-text output that you submit with or without edits.
